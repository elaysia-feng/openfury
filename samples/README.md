# Sample calls

Real phone calls placed by HumanBit's deployment of openfury. The people answering are
Shivam and Apoorv from the HumanBit team, playing candidates. They agreed to publish these.

Stereo mp3: the agent on one channel, the candidate on the other.

To add a sample for a new use case, record a simulated call with `examples/demo_call.py`.
Never add a real candidate's call. See [CONTRIBUTING.md](../CONTRIBUTING.md#dont-commit-real-people).
