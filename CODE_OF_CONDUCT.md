# Code of Conduct

openfury follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and criticise code, not people. Harassment,
discrimination and personal attacks are not tolerated, in issues, pull requests,
discussions or anywhere else the project lives.

Report a problem privately to **shivam@humanbit.ai** or **apoorv@humanbit.ai**. Reports are
kept confidential. The maintainers will act on them as the Covenant describes, up to removing
someone from the project.
